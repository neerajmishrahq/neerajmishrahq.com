# neerajmishrahq.com

Personal website of **Neeraj Mishra** (`neerajmishrahq`), Senior Software Developer.

Live: https://neerajmishrahq.com

A static one-page site (plain HTML/CSS, no build step) hosted on Cloudflare Pages.

- `index.html` — the page (SEO meta, Open Graph, JSON-LD `Person` schema)
- `assets/` — optimized photos, share image, icons
- `robots.txt`, `sitemap.xml` — for search engines
- `_headers` — Cloudflare Pages response headers
- `404.html` — not-found page

Brand icons from [Simple Icons](https://simpleicons.org) (CC0).
